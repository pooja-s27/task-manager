# Task Manager

A full-stack task management application built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Add new tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in MySQL database
- REST API integration

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- REST API
- Git & GitHub

## How to Run

### 1. Clone the repository

git clone https://github.com/pooja-s27/task-manager.git

### 2. Open the project

Open the project in IntelliJ IDEA.

### 3. Configure MySQL

Create a MySQL database named `taskmanager`.

Configure the database password using the `DB_PASSWORD` environment variable.

### 4. Run the application

Run `TaskManagerApplication.java` from IntelliJ IDEA.

### 5. Open the application

Open http://localhost:8080 in your browser.

## Project Structure

- `controller` - Handles REST API requests
- `model` - Contains the Task entity
- `repository` - Handles database operations
- `static` - Contains HTML, CSS, and JavaScript files
- `application.properties` - Application and database configuration
